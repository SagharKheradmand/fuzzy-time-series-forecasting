
# Fuzzy Time Series Forecasting from Scratch

## Overview

This project implements First-Order and High-Order Fuzzy Time Series (FTS) models from scratch for time-series forecasting.

The models are evaluated on:

- Mackey-Glass chaotic time series
- Influenza specimen count time series

The project builds fuzzy partitions, generates Fuzzy Logical Relationship Groups (FLRGs), performs one-step-ahead forecasting, and compares different model orders and partition counts.

## Main Features

- First-Order Fuzzy Time Series
- High-Order Fuzzy Time Series
- Triangular, Trapezoidal, and Gaussian Membership Functions
- Fuzzy Logical Relationship Groups
- Grid Search over Model Orders and Partitions
- RMSE, MAE, and MAPE Evaluation
- Forecast Visualization
- Interactive Prediction Interface

## Technologies

Python · NumPy · Pandas · Matplotlib · OpenPyXL
